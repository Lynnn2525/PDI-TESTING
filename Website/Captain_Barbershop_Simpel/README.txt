CAPTAIN BARBERSHOP - VERSI SEDERHANA

Isi: index.html, booking.html, bookings.html, login.html, schedule.html, script.js, stylish.css.

Cara mencoba:
1. Ekstrak ZIP ke satu folder.
2. Buka index.html di browser. Jika browser membatasi penyimpanan file lokal, buka folder memakai ekstensi Live Server di VS Code. Tidak perlu npm atau Node.js.
3. Buka Login. Akun admin demo:
   Email: admin@captainbarbershop.local
   Password: Admin123!
4. Pelanggan dapat membuat akun melalui form Daftar, lalu login.
5. Admin dapat mengubah status booking dan mengatur jadwal barber.
6. Pelanggan dapat membuat booking dan membatalkan booking yang masih Menunggu.

Catatan penting:
- Data disimpan di localStorage browser, bukan database server. Data tidak tersinkron antarperangkat.
- Login admin dan pelanggan di versi ini untuk demo/tugas kuliah saja; bukan keamanan untuk website publik karena data dan logika berjalan di browser.
- Gunakan Live Server jika localStorage pada file:// tidak berfungsi di browser yang digunakan.
